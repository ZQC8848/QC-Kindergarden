# QC 女伴 03 · 香槟可可

- **显示名 / 角色标签**：香槟可可（QC 的派对女伴之一）
- **故事 / 功能**：海边派对中的成年宾客；适合坐姿把 Haide 温柔地揽在身侧，形成安静、慵懒的包围感。
- **身体轮廓**：柔和、圆润、曲线感明显，整体重心较低，与前两位形成不同剪影。
- **头发 / 头部**：蓬松的浅亚麻金长波浪发，侧分，发量大但造型简洁。
- **服装配色**：香槟白 `#E9DCC8` × 可可棕 `#60443A` × 玫瑰金 `#B98278`；避免牧师的高饱和金黄与软软的珊瑚粉。
- **服装**：香槟白斜肩针织礼服、可可棕薄披肩、玫瑰金细带鞋与单只宽手镯。
- **标志道具**：无；她的识别重点是长波浪发、低重心轮廓和斜肩线。
- **强制无眼处理**：以 `qc-companion-champagne_turnaround_v1.png` 为视觉权威。不画眼睛、瞳孔、虹膜、眼白或高光；侧分发丝与眉骨阴影覆盖完整眼区，只保留小鼻子和放松的笑。
- **视觉优先级**：色彩柔和、细节克制，不把香槟材质做成金色闪耀主角。
