# QC 女伴 02 · 酸橙可可

- **显示名 / 角色标签**：酸橙可可（QC 的派对女伴之一）
- **故事 / 功能**：海边派对中的成年宾客；能把 Haide 抱在臂弯里一起笑闹，形成活泼但次要的动作线。
- **身体轮廓**：健康、丰润、运动感强，四肢与肩背比另外两位更有力量感。
- **头发 / 头部**：浓咖啡色高位编织马尾，发尾短而蓬，形成醒目的向上轮廓。
- **服装配色**：酸橙绿 `#A8C95A` × 浓咖啡 `#3A2620` × 奶油白 `#F4EBD7`；绿色更明亮偏黄，不使用 Whiskle 的苔藓绿关系。
- **服装**：酸橙绿短款派对夹克、奶油白简洁连衣裙、咖啡色腰带与厚底凉鞋。
- **标志道具**：一对宽幅奶油色手镯。
- **强制无眼处理**：以 `qc-companion-lime_turnaround_v1.png` 为视觉权威。不画眼睛、瞳孔、虹膜、眼白或高光；用额发、眉骨和深色软阴影完整遮住眼区，可保留开朗嘴形。
- **视觉优先级**：保持低于主角的细节密度；酸橙色只作清楚轮廓，不产生霓虹发光效果。
