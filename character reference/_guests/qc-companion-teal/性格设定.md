# QC 女伴 01 · 青铜海盐

- **显示名 / 角色标签**：青铜海盐（QC 的派对女伴之一）
- **故事 / 功能**：海边派对中的成年宾客；用于表现 Haide 被自然地抱起、宠爱和围在中心，但本人始终保持视觉次要。
- **身体轮廓**：高挑、修长、肩线利落；站姿松弛，动作优雅。
- **头发 / 头部**：深可可色下颌短波波头，一侧别到耳后，轮廓清爽。
- **服装配色**：深青绿 `#157A78` × 象牙白 `#F6EFE4` × 铜色 `#B66A45`；无大面积橙、紫、深红或靛蓝。
- **服装**：简洁的青绿挂脖连体裤、象牙白薄披肩、铜色圆环耳饰和细带凉鞋。
- **标志道具**：小型铜色贝壳手包。
- **强制无眼处理**：以 `qc-companion-teal_turnaround_v1.png` 为视觉权威。不画眼睛、瞳孔、虹膜、眼白或高光；整个眼区由刘海与眉骨下的柔和阴影覆盖，只保留简化鼻子和轻微微笑。
- **视觉优先级**：材质和轮廓与主角同属针织毡毛世界，但配饰更少、对比更低，不抢 Haide 或 QC 的视觉中心。
