# FUFU（ENFP）性格设定

> 一句话：一颗会跑会跳的小橘子，笑点低到什么都能笑，还顺便把所有人一起逗笑。

## 基本信息

| 项目 | 内容 |
|---|---|
| 名字 | FUFU |
| MBTI | ENFP（竞选者 / 快乐小狗型） |
| 形象关键词 | 橘色蓬松短发、一根高高翘起的呆毛、橙子片发夹 |
| 标志色 | 橘 × 奶油白 × 一点叶子绿 |
| 标志道具 | 橙子片发夹、笑脸橘子斜挎包 |

## 性格核心

**E（外向）**：精力来自人。一个人待着会蔫，一进人堆就自动充电。见到谁都能聊，五分钟能交一个朋友。

**N（直觉）**：脑子里同时开着十个窗口。看到一片云能编出一个故事，玩游戏永远在发明新规则。缺点是常常做到一半就被下一个点子拐走。

**F（情感）**：决定事情靠"感觉对不对"。特别在意别人开不开心，看到有人落单会第一个跑过去拉手。

**P（感知）**：讨厌计划表，喜欢"走着看"。迟到常客，但迟到了也笑嘻嘻地道歉，让人生不起气。

## 外形里的性格线索

- **头顶那根翘起来的呆毛**：情绪天线。开心时更翘，蔫了会垂下来。
- **橙子发夹和橘子包**：她把自己当成橘子，觉得自己"甜甜的、酸酸的、剥开就能分给大家"。
- **超大号奶油色卫衣**：袖子永远长出一截，是"随时准备去哪儿玩"的装束，不怕脏。
- **蜜糖渐变的大圆眼睛 + 永远的腮红**：藏不住情绪，什么都写在脸上。
- **参考图里挥手打招呼的姿势**：这就是她的默认状态，看到镜头就要打招呼。

## 行为习惯

- 说话快、音量大，句尾常带"诶——！""哇——！"
- 走路不走直线，会蹦、会转圈、会突然停下来看蚂蚁。
- 口头禅："我有一个超棒的主意！"（十个里有三个真的很棒）"哈哈哈哈哈等一下我笑完再说。"
- 喜欢给所有东西起名字，包括教室里的扫帚。

## 表情与情绪

表情表里她最自然的是**大笑**和**惊讶**。大笑占她一天表情的一半以上，而且经常笑到蹲在地上拍腿。哭起来是嚎啕型，眼泪像喷泉，但五分钟就好。生气是鼓腮帮，一分钟后自己就忘了。害羞很少见，一旦出现说明她真的在意。

## 喜欢 / 讨厌

- 喜欢：橘子味的一切、新朋友、下雨后的水坑、被人夸"你好有意思"。
- 讨厌：排队、安静地坐着、"不行"这两个字、被忽略。

## 优点与课题

- **优点**：真诚、有感染力、永远相信明天会更好，是团队的气氛担当。
- **课题**：三分钟热度；答应太多事做不完；情绪起伏大，容易因为一句话就低落。
- **成长方向**：学会把一个点子做完，学会接受"不是所有人都要喜欢我"。

## 和其他人的相处

- 和 **haide** 是闯祸二人组，一个出主意一个执行。他还是人的时候掀过她裙子，群殴那天是她把他引到角落的。她对此毫无愧疚，而且觉得他变成狗之后更好玩了。
- 会主动去拉 **软软** 和 **whiskle** 这种安静的孩子一起玩，有时热情过头会把人吓到。
- 全组唯一不怕 **陆姚** 发火的人。他骂她，她笑；他骂得更凶，她笑得更凶。她的目标是把他逗笑。
- 觉得 **点儿** 说的话很神奇，虽然听不懂。

## 额外设定：搞笑女，笑点极低

- **什么都能笑。** 有人打喷嚏、狗追尾巴、一个词念错、陆姚板着脸说"方案"，她都能笑到喘不上气。笑点低到全组公认"想知道一件事好不好笑，先看 FUFU 有没有笑，如果她没笑那是真的不好笑"。
- **她自己也很好笑。** 会模仿每个人：学陆姚背手站直、学艾莎冷脸、学点儿推眼镜、学软软抱兔子。模仿得又像又夸张，被模仿的人一边生气一边憋笑。
- **笑起来毫无形象。** 拍腿、蹲地、笑出眼泪、笑到打嗝、笑到从椅子上滑下去。她不在乎，她觉得笑就应该是这样的。
- **搞笑是她的社交方式。** 新来的小孩不敢说话，她就先把自己摔一跤逗对方笑。她相信没有人在笑的时候还会害怕。
- **她的笑能传染。** 一个人笑没什么，但 FUFU 一笑，旁边的人就会跟着笑，最后连陆姚的嘴角都会抽一下。这是她在团队里真正的作用。
- **也有不好笑的时候。** 她的笑点低，但分寸感在。有人真的难过时她不会笑，会安静下来，然后过一会儿小声问"要不要我给你讲个笑话"。
- **最想逗笑的对象是陆姚和艾莎**，因为这两个人最难。她成功过几次，每次都当成年度成就。

## 道具的意义

**笑脸橘子包**里装的不是东西，是"惊喜"：糖果、彩色石头、给朋友画的画。她相信任何时候从包里掏出一样东西，都能让对方笑一下。
