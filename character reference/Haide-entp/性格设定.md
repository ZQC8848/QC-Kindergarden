# Haide（ENTP）性格设定

> 一句话：全组智商最高、名气最大的那个，是一条狗。而且他以前不是狗。

## 基本信息

| 项目 | 内容 |
|---|---|
| 名字 | Haide |
| MBTI | ENTP（辩论家 / 捣蛋鬼型） |
| 形象关键词 | 哈士奇幼犬、四足、灰白毛、蓝眼睛、露小尖牙的坏笑 |
| 物种 | 现在是狗。以前不是。 |
| 标志色 | 深灰 × 奶白 × 红项圈 |
| 标志道具 | 红色皮革项圈、圆形银色名牌 |

## 性格核心

**E（外向）**：精力过剩。安静三分钟就要找点事做，最好是能让所有人一起动起来的事。

**N（直觉）**：擅长看到"另一种可能"。规则对他来说是用来测试边界的，而不是用来遵守的。他的脑子转得比所有人都快，快到经常自己都跟不上。

**T（思考）**：讲道理，而且很会讲。你说"不可以"，他会问"为什么"，你答不上来他就赢了。不太在意别人的感受，不是故意伤人，是没想到。

**P（感知）**：临时起意的大师。计划是什么？计划就是先跑起来再说。

## 外形里的性格线索

- **粗粗的、上扬的眉毛**：他是全组表情最丰富的角色，眉毛能单独演戏。
- **露出来的小尖牙**：不是凶，是"我又想到一个坏主意"的标志笑容。
- **蓝得发亮的大眼睛**：好奇心的具象化。盯着什么东西看超过三秒，那个东西就要遭殃了。
- **红项圈和名牌**：他唯一愿意戴的"规矩"，因为那是别人认真给他的。名牌上写着名字，他很得意。
- **卷起来的尾巴白尖**：兴奋时摇得像螺旋桨，是最诚实的情绪指示器。

## 行为习惯

- 说话像连珠炮，喜欢反问："那为什么不能……？"
- 最爱玩的游戏是"这个能不能被拆开"。
- 会叼走别人的东西，不是想要，是想看对方的反应。
- 口头禅："试试嘛！""我有更好的办法。"

## 表情与情绪

表情表里最出彩的是**得意坏笑**和**震惊瞪眼**。生气是皱眉撇嘴的"不服"，而不是真正的愤怒。哭得很少，一旦哭了是嚎啕大哭型，说明真的委屈到极点。害羞时会把脸别开，但耳朵会红。

## 喜欢 / 讨厌

- 喜欢：新东西、辩论赢了的瞬间、追着跑的游戏、被夸"聪明"。
- 讨厌："因为规定就是这样"、重复做同一件事、被当成小孩子哄。

## 优点与课题

- **优点**：反应快、点子多、从不害怕权威，能在僵局里找到出口。
- **课题**：说话不过脑子会伤人；开头很多收尾很少；把"赢"看得比"对"重要。
- **成长方向**：学会在开口前想一秒"对方会怎么想"，学会把一件事做完。

## 和其他人的相处

- 和 **Fufu** 是闯祸搭档，两人在一起智商翻倍、破坏力翻四倍。
- 最爱找 **陆姚** 抬杠，因为陆姚认真回应他每一句话，然后炸了追着他满院子骂。他觉得这是全世界最好玩的游戏。
- 和 **艾莎** 是全组仅有的两个"真正聪明的人"。辩论他赢，下棋她赢，两人心照不宣。他从不拿她的口吃开玩笑，这是他唯一的底线。另外，他最近总是莫名其妙倒霉：骨头不见、垫子变湿、球滚进下水道。他觉得概率不对，闻得出来是她，但找不到证据。这是他唯一解不开的题。
- 会偷偷把 **软软** 的兔子叼走藏起来，然后看她哭了又赶紧还回去。

## 额外设定：一条狗，却是全组最聪明、最出名的

- **智力是公认的第一。** 不是"狗里面最聪明"，是所有角色里最聪明。艾莎的计划、点儿的原理、陆姚的方案，最后都会拿去给他过一遍，他闻一闻就能说出哪里有问题。
- **他自己完全不在乎这件事。** 聪明对他来说是拿来玩的，不是拿来炫耀的。别人惊叹"这是一条狗想出来的？"，他只会歪头："所以呢？"
- **名气比人还大。** 幼儿园外面的人可能叫不出其他角色的名字，但都听说过"那条会解题的哈士奇"。他有粉丝，有传说，有人专门来看他。他对这些人的反应是：叼走对方的鞋。
- **"只是一条狗"是他最大的笑点和最大的反差。** 他会追自己的尾巴，会被吸尘器吓到，然后转头解出一道所有人都不会的题。考虑到他以前是个人，追尾巴这件事更好笑了。
- **聪明带来的孤独。** 他很少遇到能真正跟上他思路的人，所以他捣蛋，因为捣蛋是他能让所有人一起参与进来的方式。艾莎和点儿是少数能让他"认真说话"的对象。

## 事件档案（已迁移）：他以前不是狗

- **他原本是个男孩。** 和大家一样，两条腿走路，穿衣服，坐小板凳。聪明、爱捣蛋、嘴欠，和现在一模一样，只是当时有手。
- **有手的时候干的最缺德的事：撩女生裙子。** 不是偶尔，是天天。趁人不注意从后面掀一下就跑，跑的时候还回头笑。Fufu 被掀过，软软被掀过（哭了一下午），艾莎被掀过（当场记进红书），Mimi 被掀过（这是他犯的最大的错误）。
- **然后他被女生们群殴了。** Mimi 带头，艾莎出的方案，Fufu 负责把他引到角落，软软抱着兔子在旁边看，看着看着也上去踢了一脚。打完之后 Mimi 把棒球棒往地上一杵，让他发誓：**"再犯一次，就变成一条狗。"** 他当时满脸是土，满口答应，心里想的是"这算什么誓言"。
- **但是……** 第二天他就又犯了。掀的还是 Mimi。
- **后来居然真的变成狗了。** 没人知道怎么回事。没有闪光，没有烟雾，就是某天早上大家到教室，发现他的小板凳上蹲着一只哈士奇幼崽，眼睛还是那双蓝眼睛，眉毛还是那对眉毛，露着小尖牙冲大家笑。Mimi 第一个反应过来，蹲下去看了他三秒，说："我说过的。"
- **他自己对这件事的态度：无所谓。** 一开始惊讶了一下，然后发现四条腿跑得比两条腿快，牙比拳头好用，还没人能再逼他穿衣服，就接受了。他唯一抱怨过的是"没手不能掀裙子了"，说完被 Mimi 追着打了一圈。
- **变成狗之后他确实没再掀过。** 不是改邪归正，是物理上做不到。女生们对此的评价是："誓言果然有用。"
- **这件事是他名气的来源之一。** 外面的人不只听说"那条会解题的哈士奇"，还听说"那条因为掀裙子被变成狗的哈士奇"。他觉得后一个说法有损形象，但也没办法。
- **红项圈是变成狗之后 Mimi 给他戴的。** 名牌上的名字是她写的。他说这是"羞辱"，但从来没摘下来过。
- **没人知道能不能变回去。** 他自己好像也不太想知道。偶尔有人问"你想变回人吗"，他会歪头想很久，然后说："变回去还得穿裤子。"
- **他的远房表叔 QC 是幼儿园的董事长。** 表叔说在找把他变回人的办法，但每次来看他都过得太滋润，积极性就又降了一点。他从没催过。表叔来了他会跑过去蹭腿，走了会送到门口，这是他在幼儿园里最松弛的一段关系。手链上那颗小贝壳是他还是人的时候在沙滩上捡给表叔的，表叔一直戴着。
- **他咬过表叔一个星期。** 起因是艾莎拿着红书去董事长那儿告状，表叔半开玩笑说"实在不行做个小手术阉割一下"。他听懂了，扑上去咬住裤脚，追着咬了七天，直到表叔举手投降发誓"永远不做"。
- **投降的条件是每月底的派对。** 表叔开着金色法拉利带他去满是美女的派对，他一晚上被一个接一个身材丰满的美女搂在怀里，尾巴摇成螺旋桨，一脸"人生巅峰"。表叔在旁边看着，第一次说了"感觉当狗也挺不错的"。这是他每个月最期待的一天。
- **表叔每次来都会多带一份麦当劳。** 不说是给谁的。表叔绕一圈、摸摸每个孩子的头、走到他面前，那份麦当劳就不见了。他不知道表叔为什么突然开始这样，也没问。艾莎偶尔会注意到他嘴边的番茄酱。
- **娱乐室里那台 PS5 是表叔买的，基本是他专用。** 一只狗蹲在沙发上用爪子按手柄，全园早就见怪不怪，没人再多看一眼。手柄上有牙印。他玩什么没人在意。
- **他玩的是《王者兰特》，ID 叫"掀桌"。** 全服第一，从开服第一天到现在从来没变过，论坛上几百个帖子在猜"掀桌"是何方神圣，没人猜到是一条狗。他不发视频，不聊天，不组队，定榜那天也不看榜。对他来说这不是排名，是散步。
- **他知道点儿看到了。** 那天点儿路过娱乐室，在他身后愣了五秒，他没回头。后来点儿再路过，他头也不回地说了一句"别看了，学不会的"。点儿走得很快。他没跟任何人提过，点儿也没有。两个人心照不宣。
- **他也知道"点到为止"和"夜行玫瑰"是谁。** 每个月定榜前夜看着这两个 ID 在自己下面打得你死我活，他觉得挺可爱的。偶尔会故意在凌晨四点上线，把两个人一起清空，然后下线睡觉。
- **关于金色法拉利，他什么都没承认。** 表叔偶尔收到凌晨的超速罚单，主驾驶座上有哈士奇的毛，市里传说有一只狗开着法拉利在高速上狂飙。表叔蹲下来问"是你吗"，他歪头、眨眼、打哈欠、跑去追 Fufu。点儿算过，"理论上可行，但需要极高的智商"。

## 道具的意义

**红项圈**是他和这个群体的连接，也是那场群殴和那句誓言留下的唯一实物。他可以不听话，但从来不会把项圈弄丢。名牌上的名字是 Mimi 写的，提醒他：你干过什么，以及有人在乎你叫什么。
