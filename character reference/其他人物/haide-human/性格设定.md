# 人类形态 Haide（临时形态）

- **显示名**：Haide（变成狗以前）
- **故事 / 功能**：只用于《Haide 变成狗的那一天》中誓言生效以前的画面；属于 Haide 的过去形态，但按临时人物的视觉层级处理。
- **身体轮廓**：精瘦、灵活、略向前探的男孩体态，重心像随时准备转身逃跑；Q 版比例与幼儿园角色一致，但细节更少、对比度更低。
- **头发 / 头部**：灰黑色凌乱短发，额心有一束奶白色尖形挑染，对应哈士奇额头的白纹；头顶两侧发束略向上翘，但不是动物耳朵。
- **服装配色**：炭灰与奶白的短连帽外套、灰黑短裤、奶白运动鞋；只用少量暗红鞋带作视觉联系。此时尚未拥有红项圈或银色名牌。
- **识别特征**：奶白色额发、小尖犬齿、带挑衅感的歪嘴笑；不使用狗耳、狗尾或其他变形后的身体特征。
- **强制无眼处理**：不画可见眼睛、瞳孔、虹膜、眼白、眼部高光或眉毛。整个眼区是一块连续的平滑哑光阴影色块，由碎发遮住上沿；阴影主体保持均匀纯色，仅在与脸颊衔接的下缘使用一条很窄的柔和羽化过渡。色块内没有任何五官线条，也没有毛绒、针织、纤维、颗粒或斑驳质感。可以保留鼻子和嘴，但必须一眼读成临时人物。
- **视觉优先级**：低于在场的长期角色，不使用高饱和大面积色块或繁复配饰。
