# lukos（INFJ）性格设定

> 一句话：话不多，但总在你需要的时候出现，手里还拿着一束刚好合适的花。

| 项目 | 内容 |

| 名字 | lukos |

## 性格核心

**I（内向）**：人多的地方会消耗他。喜欢待在角落观察，一个人的时候反而最放松。

**N（直觉）**：看事情看"底下那一层"。别人说"我没事"，他能听出来是真没事还是假没事。对人的情绪极其敏感。

**F（情感）**：做决定先想"这样对大家好不好"。自己受委屈可以忍，看到别人受委屈忍不了。

**J（判断）**：内心其实有很清晰的秩序。他的安静不是没主意，是在等一个说出来的时机。一旦做了决定就很固执。

## 外形里的性格线索

- **上扬的担忧眉毛**：默认表情就是"有点担心"。不是真的在担心什么，是他随时在留意周围人的状态。
- **围到下巴的超厚围巾**：他的安全屏障。围巾越厚，说明他越需要一点距离。把围巾借给别人是他表达"我很在乎你"的方式。
- **超大号开衫和木头纽扣**：温和、旧旧的、让人放心的质感。
- **蓝灰色的头发和眼睛**：整体色调是"阴天"，但是温柔的那种阴天。
- **粉色郁金香**：唯一的亮色，说明他心里其实很软、很浪漫。

## 行为习惯

- 说话慢，音量小，但每句话都是想好的。
- 会记住每个人随口说过的事，然后在生日那天拿出来。
- 习惯性地把手缩进袖子里。
- 口头禅："你还好吗？""要不要……我陪你？"

## 表情与情绪

表情表里最有辨识度的是**害羞**和**担忧**。开心是小小的、抿嘴的笑，很少大笑。生气不是爆发，是眉毛皱得更紧、不说话。哭是无声的，眼泪往下掉但嘴巴闭着。骄傲的表情最不自然，他不太习惯为自己得意。

## 喜欢 / 讨厌

- 喜欢：安静的午后、一对一的长谈、下雪、给别人准备小惊喜。
- 讨厌：吵架、被人当众夸奖、被迫做选择、看到有人被孤立。

## 优点与课题

- **优点**：共情力极强、可靠、有原则，是大家的秘密守护者。
- **课题**：太在意别人而忘了自己；不擅长说"不"；憋太久会突然崩溃。
- **成长方向**：学会说出自己的需要，允许自己也被照顾。

## 和其他人的相处

- 和 **软软** 是安静的好朋友，两个人可以并排坐一下午不说话。
- 是 **FUFU** 和 **haide** 闯祸后收拾残局的人，虽然嘴上不说什么。
- 对 **牧师** 的热情有点招架不住，但很信任他。
- 会默默观察 **爱莎**，觉得她其实比看起来更孤独。

## 道具的意义

**郁金香花束**不是给某一个人的，是他随身携带的"温柔的储备"。谁难过了，就递过去一支。**围巾**则是他自己的温柔储备，围紧了是给自己的，解开借出去是给别人的。
