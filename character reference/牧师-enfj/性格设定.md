# 牧师（ENFJ）性格设定

> 一句话：像一小团金色的太阳，走到哪里就把哪里照亮，还顺便记住你今天为什么不开心。然后忍不住讲给别人听。

## 基本信息

| 项目 | 内容 |
|---|---|
| 名字 | 牧师 |
| MBTI | ENFJ（主人公 / 小太阳型） |
| 形象关键词 | 金色蓬松乱发、高高的呆毛、张嘴大笑、金黄色的斗篷和绶带 |
| 标志色 | 金黄 × 奶油 × 棕 |
| 标志道具 | 金色十字架吊坠、奶油色祈祷书、绣着太阳纹的金色绶带 |

## 性格核心

**E（外向）**：被人需要的时候最有精神。他是那种会主动走过去问"你还好吗"的人，而且真的想知道答案。

**N（直觉）**：看到每个人身上的"好"。哪怕是最捣蛋的孩子，他也能说出对方三个优点。

**F（情感）**：温度极高。别人的开心他会跟着开心，别人的难过他会比对方还难过。

**J（判断）**：有责任感。答应的事一定做到，会主动把大家组织起来，而且组织得很温柔。

## 外形里的性格线索

- **张开嘴的大笑和琥珀色的眼睛**：默认表情就是笑。他的笑是发自内心的，眼睛会弯起来。
- **金色的斗篷和绣满太阳的绶带**：他把自己当成"给别人带光的人"。
- **牧师领和十字架**：不是宗教意味，是"我在这里守护你"的象征。
- **蓬松的、有点乱的金发和高高的呆毛**：说明他其实很随性，一点也不端着。
- **裤脚和靴子上的十字绣花**：从头到脚都是同一套信念，很纯粹。

## 行为习惯

- 说话温暖，喜欢叫每个人的名字，喜欢说"没关系的"。
- 会给每个人一个拥抱，包括不想被抱的人。
- 每天晚上会把今天谁不开心记在祈祷书里。
- 口头禅："你听说了吗？""没事的，有我在。""你今天已经很棒了。""我跟你说，你别跟别人说。""……好吧好吧我告诉你。"

## 表情与情绪

表情表里最本色的是**开怀大笑**和**温柔的微笑**。惊讶时嘴巴张成圆形，很可爱。生气极少，一旦出现是"为别人生气"，眉毛压下来但眼睛还是亮的。哭是大颗眼泪往下掉，但他哭完会先安慰旁边的人。害羞时会挠头，呆毛会晃。

## 喜欢 / 讨厌

- 喜欢：大家聚在一起、有人对他说谢谢、晴天、唱歌、看到别人和好。
- 讨厌：有人被孤立、争吵、说别人坏话、被人说"你太天真了"。

## 优点与课题

- **优点**：温暖、可靠、有凝聚力，是团队的粘合剂。
- **课题**：太想让所有人都开心，把自己排在最后；不会拒绝；被辜负了会很受伤但还是会原谅；嘴太快，守不住任何秘密。
- **成长方向**：学会说"我今天也不太好"，学会接受有些人就是不需要被拯救。

## 和其他人的相处

- 和 **Mimi** 都是 ENFJ，一个是太阳一个是队长。他负责"让大家愿意来"，她负责"让大家不散"。
- 是 **Lukos** 最信任的人，因为他的热情是真的，不是表演。
- 会拉着 **艾莎** 和 **陆姚** 一起玩，两个人嘴上拒绝但都会来。艾莎说话卡住的时候，他是唯一会安静等她说完、不接话也不催的人。
- 是 **Fufu** 最稳定的观众，她讲什么他都会笑，两个人凑一起整间教室都在笑。
- 对 **Haide** 无限包容，是唯一从来不会骂他的人。

## 额外设定：消息通、万事屋、以及守不住的分享欲

- **他知道幼儿园里发生的一切。** 谁和谁吵架了、谁偷偷喜欢谁、陆姚今天为什么炸、QC 这次带的阿姨叫什么、Liiie 这周请了几天假。一半是大家主动告诉他的，因为他会认真听；另一半是他自己问出来的。
- **他是全园的万事屋。** 找东西、传话、调解、问路、借橡皮、打听消息，都找牧师。他的祈祷书后半本是各种委托记录，前半本才是大家的心情。
- **他有时候会表现得很八卦。** 一听到"你知道吗……"眼睛就亮了，会凑过来，会追问"然后呢然后呢"。这和他温柔的形象不太搭，但很真实。他自己的解释是"关心大家嘛"。
- **他打听起来没有边界感。** 看见谁脸色不对就直接坐过去："怎么啦？跟我说说。"对方说没事，他换个角度再问一遍，问到说出来为止。他不觉得这叫打听，他觉得这叫关心，而且大部分时候这两件事确实分不开。
- **听到一半他就开始想告诉谁。** 消息还没听完，他脑子里已经排好了接下来要讲给谁听的顺序。打听和转述对他来说是同一件事的两半，缺哪一半都难受。
- **分享欲是他的软肋。** 他就是想说。知道一件事却不能说，对他来说比什么都难受。所以所有人都学会了一个技巧：想知道什么，只要走到他面前，安静地看着他，数到十，他自己就会开口。
- **他也知道这样不好。** 每次说漏嘴之后都会很懊恼，在祈祷书里写"今天又没忍住"。第二天照旧。
- **他真正忍住过一次。** Haide 每月底跟 QC 去派对的事他知道一点，但 Haide 说了"你敢说我咬你"。他看过 Haide 咬 QC 一个星期是什么样，所以这次真的没说。这是他有记录以来最长的一次保密。
- **但他有底线。** 真正会伤害人的事他不说。软软的摩托车幻想他不知道，如果知道了也不会说。艾莎的口吃他从不拿出来讲。Haide 变成狗的真正原因他知道得比谁都清楚，但对外面的人他只说"那是我们园里的狗"。他的八卦是无害的那种，是"谁今天穿了新鞋"级别的。
- **信息在他这里是流通的，不是囤积的。** 这和艾莎的红书完全相反：艾莎记下来是为了用，他记下来是为了讲。所以艾莎从不告诉他任何事，而他知道艾莎不告诉他，也不在意。
- **他的情报网最大的受益者是 Fufu。** Fufu 想逗笑谁，就先去问牧师"那个人今天心情怎么样"。牧师从来不用她问第二遍。

## 道具的意义

**十字架吊坠**是他的承诺：我在这里。**祈祷书**里写的不是祷告，前半本是每个人的名字和他们今天的心情，后半本是万事屋的委托记录和"今天又没忍住"。**太阳绶带**是他对自己的期望：当别人的光。
