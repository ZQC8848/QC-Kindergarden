# Mimi（ENFJ）性格设定

> 一句话：扛着棒球棒的孩子王，谁受欺负她第一个冲上去。

## 基本信息

| 项目 | 内容 |
|---|---|
| 名字 | Mimi |
| MBTI | ENFJ（主人公 / 大姐头型） |
| 形象关键词 | 深紫色刺猬头、高高的侧马尾、星星发夹、自信的斜眼笑 |
| 标志色 | 紫 × 黑 × 白 |
| 标志道具 | 银色棒球棒（紫色握把和条纹）、银色星星发夹 |

## 性格核心

**E（外向）**：天生站在人群中央。不是她想当中心，是大家自然会看向她。

**N（直觉）**：能看见"这群人可以变成什么样"。她对人的期待很高，因为她真的相信你能做到。

**F（情感）**：护短。自己人受一点委屈她能记一年。表面凶，其实是全组最会照顾人的，只是方式比较直接。

**J（判断）**：说到做到，讨厌拖泥带水。会给大家分配任务，而且真的会检查。

## 外形里的性格线索

- **眯起来的紫色眼睛和小小的得意笑**：默认表情是"我罩着你们"。
- **刺猬一样竖起来的头发**：能量往外炸的视觉化。侧马尾是她少有的"女孩子气"，但扎得很高，还是很飒。
- **敞开穿的棒球外套 + 黑色帽衫**：运动系、随时能打一架的装束。胸口的白星是她的标志，代表"队长"。
- **左右不一样的袜子**：她故意的。规则是她定的，所以她可以不遵守。
- **棒球棒**：她说是打棒球用的。没人见过她打棒球。

## 行为习惯

- 说话干脆，喜欢用祈使句："走。""别哭。""跟我来。"
- 走路带风，棒球棒扛在肩上。
- 会不动声色地把最好的位置留给最小的孩子。
- 口头禅："有我在。""谁欺负你了？"

## 表情与情绪

表情表里最本色的是**自信的坏笑**和**皱眉生气**。真正大笑时会露出完全不同的一面，像个普通小孩。害羞的时候会用棒球棒挡脸。哭得极少，一旦哭了会先转过身去，不让人看见。

## 喜欢 / 讨厌

- 喜欢：带队、赢、被信任、看到自己人变强。
- 讨厌：欺负弱小的人、说话不算话、有人对她说"你一个女孩子"。

## 优点与课题

- **优点**：有担当、行动力强、天然的领导者，是团队的主心骨。
- **课题**：控制欲；把"为你好"当理由替别人做决定；不允许自己示弱。
- **成长方向**：学会问"你想要什么"而不是直接给答案，学会让别人也保护她一次。

## 和其他人的相处

- 和 **牧师** 都是 ENFJ，但风格完全不同：她靠气场，他靠温度。两人有时会争谁说了算，但配合起来无敌。
- 是 **软软** 的守护者，任何人让软软哭了都要过她这一关。
- 和 **陆姚** 互相看不顺眼又互相佩服，是"两个队长"的关系。幼儿园实际上是这两个人在管。
- 对董事长 **QC** 的评价是"没用但无害"。他搞不定哭着的软软，最后都是一句"这个交给你了"甩给她。她的回应永远是"你别添乱就行"。
- 对 **Haide** 的捣蛋容忍度最低，但也是最常帮他收拾烂摊子的人。Haide 还是人的时候掀她裙子，是她带头把他群殴了一顿、逼他发誓"再犯就变成狗"的。后来他真变成狗了，她的第一反应是"我说过的"。项圈和名牌是她给他戴的。

## 道具的意义

**棒球棒**从来没有真的打过人。它是"我有能力保护你"的宣言，扛在肩上是威慑，放下来是信任。**星星发夹**是她的队长徽章，外套上、袜子上、鞋上到处都是星星，她把自己当成大家的星星。
