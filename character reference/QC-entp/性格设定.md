# QC（ENTP）性格设定

> 一句话：幼儿园的董事长，一年来不了几次，每次来都穿着花衬衫、端着橙汁、带着一个新的女伴。

## 基本信息

| 项目 | 内容 |
|---|---|
| 名字 | QC |
| MBTI | ENTP（辩论家 / 甩手掌柜型） |
| 身份 | 幼儿园董事长（挂名的）、haide 的远房表叔 |
| 年龄感 | 成年人，但在这个世界里也是 Q 版身材，和孩子们差不多高 |
| 形象关键词 | 靛蓝色乱发、压在鼻尖的墨镜、敞开的夏威夷衬衫、贝壳项链、凉鞋、永远端着一杯橙汁 |
| 标志色 | 靛蓝 × 白 × 橙 |
| 标志道具 | 黑色方框墨镜、银色贝壳项链、蓝白串珠手链、插着橙子片的冰橙汁 |

## 性格核心

**E（外向）**：走到哪儿都是派对的中心。不是他想当中心，是他一出现气氛就变了，孩子们围上来，老师们皱起眉头。

**N（直觉）**：脑子很好使，看问题一针见血。幼儿园的账目、人事、问题，他扫一眼就知道哪里有毛病。然后不管。

**T（思考）**：讲道理讲得很漂亮，尤其擅长论证"为什么这件事不用我来做"。对情绪不敏感，孩子哭了他的第一反应是递橙汁。

**P（感知）**：人生哲学是"顺其自然"。计划？没有。责任？能推就推。截止日期？那是什么。

## 外形里的性格线索

- **压在鼻尖的墨镜，眼睛露在上面**：他从不把墨镜真正戴好。戴好了是要挡太阳的，压在鼻尖是要显得酷的。这是他整个人的缩影：形式大于功能。
- **敞开的夏威夷衬衫和大裤衩**：来幼儿园开董事会也是这身。有人提醒他"注意场合"，他说"这就是我的正装"。
- **永远端着的橙汁**：一杯喝完立刻有下一杯。没人见过他手里空着。孩子们怀疑那不是橙汁，他说"你们还小"。
- **贝壳项链和手链**：每次来幼儿园都是从某个海边直接过来的。项链上的贝壳偶尔会换，说明海边也换了。
- **参考图里插着口袋的手和上挑的眉毛**：默认姿势是"我在这儿，但我不打算干活"。
- **晒黑的皮肤**：全组唯一一个肤色和别人不一样的，因为他一年有三百天在晒太阳。

## 行为习惯

- 说话慢悠悠，喜欢用"嘛""啦""随便啦"。
- 每次来幼儿园先绕一圈，摸摸每个孩子的头，然后去找 haide。
- 开会开到一半会站起来说"我去续杯"，然后就不回来了。
- 口头禅："这事儿你们看着办。""急什么，先喝杯东西。""我表侄呢？"

## 额外设定一：董事长，但是完完全全的甩手掌柜

- **他的名字在幼儿园所有文件的最上面。** 董事长、法人、创始人，全是他。但他本人一年出现的次数一只手数得过来。
- **幼儿园实际上是谁在管，他不知道。** 他以为有园长。园长以为他会管。结果是 Mimi 和陆姚在管。
- **每次来都是突然的。** 没有预告，穿着花衬衫从校车上跳下来，手里端着橙汁，身后跟着一个新的女伴。老师们手忙脚乱，孩子们欢呼，他挥挥手说"不用管我"，然后真的没人管他。
- **他对幼儿园的贡献是钱。** 而且是很多钱。他不问钱花在哪儿，只签字。陆姚曾经拿着预算表想跟他汇报，他看了三秒，签了名，说"你做得挺好"，陆姚气得帽子都歪了。
- **不是不聪明，是不想管。** 他完全看得出幼儿园的问题在哪里，偶尔喝着橙汁随口说一句，就能点破艾莎想了一个月的方案里的漏洞。然后他会说"不过我不管这个啦"。
- **对孩子们的事情很多时候束手无策。** 他能搞定合同、搞定成年人、搞定任何一场谈判，但搞不定一个哭着的软软。他试过讲道理，试过递橙汁，试过让女伴帮忙，都没用。最后他的方法是找 Mimi："这个交给你了。"

## 额外设定二：haide 的远房表叔

- **他和 haide 是亲戚，远到说不清是哪一房的。** 但两个人一见面就知道是一家的：一样的坏笑，一样的眉毛，一样的"为什么不行"。
- **haide 还是人的时候，他是全家唯一觉得"这孩子挺有意思"的人。** 别人骂 haide 捣蛋，他说"我小时候也这样"。这句话没帮 haide 少挨骂，但 haide 记住了。
- **他知道 haide 变成狗的事。** 反应是笑了整整五分钟，然后说"活该"，然后又说"不过挺可爱的"。
- **他确实在找把 haide 变回人的办法。** 问过一些人，翻过一些书，托过一些关系。这是他这几年唯一主动在做的一件事。
- **但积极性不够高。** 因为每次来看 haide，haide 都过得很滋润：四条腿跑得飞快，有人给戴项圈，有人给写名牌，全组最聪明，全园最出名，还不用穿裤子。他蹲下来看着 haide，haide 歪头看着他，两个人对视三秒，他站起来说"算了，你这样挺好的"。
- **haide 对此的态度：无所谓。** 他从来没催过表叔。偶尔会问"找到了吗"，表叔说"还在找"，他说"哦"，然后跑去追 FUFU 了。
- **两个人的关系是全组最松弛的。** 不需要说话，不需要解释，他来了 haide 会跑过来蹭他的腿，他走了 haide 会送到门口，仅此而已。这是 QC 唯一认真对待的关系。

## 额外设定三：放荡，每次带的女伴都不一样

- **他从不一个人来。** 每次都有一位女伴，每次都不是同一位。孩子们统一叫"阿姨"，然后发现下次来的是另一个阿姨。
- **女伴们的共同点：都很漂亮，都很闲，都不知道自己为什么会在幼儿园。** 她们通常站在他身后，微笑，然后被孩子们围观。
- **他对此毫不遮掩。** 有人（陆姚）指出"董事长这样不合适"，他说"哪里不合适？她们都很喜欢小孩"。陆姚炸了，他递了杯橙汁。
- **孩子们的反应各不相同。** FUFU 觉得很好玩，会给每个阿姨起外号。Mimi 翻白眼。艾莎在红书里记录每个女伴的特征，编号已经到了 017。软软觉得每个阿姨都很漂亮，不敢说话。牧师会认真地和每个阿姨聊天，问她们"今天开心吗"。
- **他不是坏人，只是没长大。** 他的放荡不是恶意，是对"责任"这个词彻底的过敏。他喜欢好看的人、好喝的东西、好玩的地方，不喜欢任何需要他明天还在同一个地方的事。
- **有一次他一个人来了。** 没带女伴，没端橙汁，蹲在 haide 旁边坐了一下午。没人知道那天发生了什么。第二次来的时候一切如常。

## 表情与情绪

表情表里最本色的是**墨镜后面的坏笑**和**懒洋洋的半睁眼**。惊讶的时候墨镜会滑下去。生气几乎没见过，最多是皱一下眉然后"算了"。哭的那格是全组最不可能出现的，但他在 haide 变成狗那天笑得眼泪都出来了，勉强算一次。害羞不存在。骄傲倒是常有，通常是在他随口点破了什么之后。

## 喜欢 / 讨厌

- 喜欢：海边、橙汁、好看的人、好玩的事、haide、"不用我管"。
- 讨厌：开会、签字之外的一切文件、被问"你打算什么时候负责"、有人叫他"董事长"（他更喜欢"QC"）。

## 优点与课题

- **优点**：聪明、大方、从不干涉、对孩子没有恶意，是这个幼儿园能存在的经济基础。
- **课题**：完全不负责任；对孩子的情绪束手无策；找 haide 变回人的事三分钟热度；把"放松"活成了"逃避"。
- **成长方向**：认真开完一次会，认真问一次 haide "你到底想不想变回来"，认真带一次同一个女伴。

## 和其他人的相处

- **haide** 是他在这个幼儿园唯一真正在意的人。详见上文。
- **陆姚** 是最恨他的人。一个想把幼儿园管好，一个是幼儿园的主人却什么都不管。每次见面陆姚都要炸一次，他每次都递橙汁。
- **Mimi** 觉得他"没用但无害"，会直接跟他说"你别添乱就行"，他说"好嘞"。
- **艾莎** 在红书里给他单独开了一章，内容包括每一位女伴的编号。她认为他"是变量，但不是威胁"。
- **FUFU** 是他最喜欢的孩子（除了 haide），因为她是唯一觉得他好笑的人。
- **牧师** 是唯一会认真跟他说"你应该多来看看孩子们"的人。他每次都说"好"，然后三个月不来。
- **软软** 看到他会躲到 Mimi 身后。他试过跟她说话，她哭了。从此他见到软软就绕道，"这个我搞不定"。
- **点儿** 和他聊过一次游戏。聊完之后点儿说"他其实很聪明"，这是点儿对成年人的最高评价。
- **Liiie** 是他觉得"有意思"的孩子。一个转学生对董事长的礼貌和对其他人一模一样，他觉得这说明她不在乎他是董事长，这让他很舒服。他隐约觉得这孩子和自己是同类：都在用一层东西把自己包起来。

## 道具的意义

**墨镜**压在鼻尖是他的态度：我看得见一切，但我选择不看。**橙汁**是他的社交工具，递出去代表"别跟我认真"。**贝壳项链**是他的来处，每一颗贝壳都是某个海边、某个女伴、某个不打算记住的下午。他唯一没换过的是手链上那颗小贝壳，是 haide 还是人的时候在沙滩上捡给他的。
