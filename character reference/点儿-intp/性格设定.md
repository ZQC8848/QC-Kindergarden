# 点儿（INTP）性格设定

> 一句话：戴着耳机的时候在想问题，摘下耳机的时候也在想问题。

## 基本信息

| 项目 | 内容 |
|---|---|
| 名字 | 点儿 |
| MBTI | INTP（逻辑学家 / 小宅男型） |
| 形象关键词 | 银灰色短发、一根细呆毛、黑框方眼镜、挂在脖子上的白色耳机、满身棋盘格 |
| 标志色 | 白 × 浅灰 × 棋盘格 |
| 标志道具 | 白色游戏手柄、白色头戴耳机（棋盘格耳罩）、黑色方框眼镜 |

## 性格核心

**I（内向）**：社交电量极低。能用一句话说完的绝不说两句，能不说的绝不说。

**N（直觉）**：对"原理"着迷。玩游戏不是为了赢，是为了搞清楚这个游戏的机制。

**T（思考）**：讲逻辑，不讲情面。别人哭了他会问"所以问题是什么"，不是冷血，是真的想帮忙解决。

**P（感知）**：没有计划，兴趣到哪儿人到哪儿。可以为一个问题熬到半夜，也可以三天不碰。

## 外形里的性格线索

- **黑框眼镜和半眯的灰蓝眼睛**：镜头感是"在思考，别打扰"。
- **挂在脖子上的耳机**：他的"请勿打扰"牌。戴上就是进入自己的世界，挂着说明还愿意听你说话。
- **全身棋盘格**：他喜欢规律、网格、可以被预测的东西。混乱让他不舒服。
- **白色和浅灰的整体色调**：低饱和度，不想引人注意。
- **参考图里放松的半笑**：不是开心，是"这个问题有点意思"。

## 行为习惯

- 说话平、慢、精确，喜欢用"其实""严格来说""理论上"。
- 被问到问题会先沉默三秒再回答，答案通常比你想要的长。
- 吃饭时也在看攻略。
- 口头禅："为什么会这样？""等一下，我算一下。"

## 表情与情绪

表情表里最本色的是**平静的半笑**和**困**。惊讶时眼镜会滑下来。生气是"无语"型，皱眉、抿嘴、转头。开心大笑非常罕见，大概只有解出一道难题时才有。哭是最不像他的表情，一旦出现说明世界观崩了。害羞时会假装推眼镜。

## 喜欢 / 讨厌

- 喜欢：游戏机制、拆东西、规律、安静、有人问他"这个是怎么做到的"。
- 讨厌：无意义的寒暄、被打断思路、"你就不能正常一点吗"、大声的环境。

## 优点与课题

- **优点**：聪明、客观、有钻研精神，是团队的"百科全书"和"问题解决器"。
- **课题**：情商在线但懒得用；开头一百个想法完成零个；不会安慰人。
- **成长方向**：学会说"我理解你现在很难过"，学会把一个项目做到能给别人看的程度。

## 和其他人的相处

- 和 **Haide** 是"两个聪明人"，一个爱拆一个爱问，经常一起研究出稀奇古怪的东西。他承认 Haide 比他聪明，这是他唯一承认过的事，而且只承认过一次。他认真研究过"一只狗能不能开法拉利"：算了前肢长度、踏板距离、转向比，结论是"理论上可行，但需要极高的智商"。写在笔记本最后一页，没给任何人看。他还听见过 Haide 在睡梦里发出发动机的声音。
- 和 **Whiskle** 最自在，两人可以并排坐一下午各干各的。他是第一眼就看出 Whiskle 是男孩子的人，理由是"骨架和站姿，很明显"，Whiskle 为此一直很感激他。
- 觉得 **Fufu** 太吵，但她是唯一能把他拉出房间的人。
- **艾莎** 是他唯一愿意认真辩论的对象。
- 和 **Liiie** 是《王者兰特》里争全服第二的死对头，但两人都没挑明。详见记忆事件《王者兰特定榜夜》。

## 事件档案（已迁移）：王者兰特

- **他玩的游戏叫《王者兰特》。** 一款竞技游戏，有全服排行榜，每个月固定一天"定榜"，定榜那一刻的排名就是这个月的最终排名。他玩了很久，很强。
- **他的游戏 ID 是"点到为止"。** 取自自己的名字，也是他的打法：不浪、不炫、算好了就收手，赢得干净。排行榜上认识这个 ID 的人都说"这人打得像在做数学题"。
- **他常年在全服第二和第三之间徘徊。** 和他争的是一个叫"**夜行玫瑰**"的 ID。这个人打法和他完全相反：凶、快、不讲道理、凌晨三点最活跃。两个人一个月里互换十几次位置，到定榜那天谁是第二谁是第三，全看最后一夜。
- **定榜前夜他一定通宵。** 耳机戴上，房门关上，手柄握到发热。那一夜他和"夜行玫瑰"会打到天亮，谁也不让谁。定榜之后他会睡一整天，第二天上课眼镜下面全是黑眼圈。
- **他怀疑"夜行玫瑰"是 Liiie。** 理由：打法里有一种"礼貌的狠"，凌晨三点在线的时间和 Liiie 的黑眼圈对得上，定榜第二天 Liiie 必然请病假。他没证据，也没问，只是在她"病假"回来的第二天多看她两眼。她也会看回来一眼。两个人从没聊过游戏。
- **但第二名从来不是目标，因为第一名是个传说。** 全服第一的 ID 叫"**狗不理**"。从开服第一天起就是第一，从来没掉下来过，一次都没有。没人见过这个人的操作视频，没人知道这个人是谁，论坛上有几百个猜测帖，全是猜的。"点到为止"和"夜行玫瑰"打得再凶，也只是在争"狗不理"下面的那个位置。
- **然后有一天，他在幼儿园娱乐室看到了。** Haide 蹲在沙发上玩 PS5。这本身已经见怪不怪了，一只狗玩 PS5，全园没人再多看一眼。他也只是路过，随便瞟了一眼屏幕。
- **屏幕左下角的 ID 是"狗不理"。**
- **他愣在原地。** 大概有五秒。Haide 没回头，爪子在手柄上按得飞快，尾巴慢悠悠地晃。屏幕上"狗不理"刚刚把对面五个人全部清空。
- **他整整一天都在想这件事。** 上课在想，吃饭在想，回家路上在想。全服第一，开服以来没变过的传说，是一条狗。是那条掀裙子被变成狗的狗。是每天追 Fufu、叼软软兔子、咬表叔一星期的狗。他重新算了一遍：一只狗，四条腿，用爪子按手柄，全服第一。理论上……理论上……他算不下去了。
- **晚上他躺在床上睡不着。** 翻来覆去到凌晨两点，脑子里全是那个 ID 和那双眯着的蓝眼睛。凌晨三点，他做了一个决定。
- **他决定忘掉这件事。** 他什么都没看到过。娱乐室里没有 PS5，屏幕上没有 ID，Haide 只是一条狗。他把这件事从脑子里划掉，像艾莎划掉红书里的那一条。
- **他从来没跟任何人提起过。** 没跟 Liiie 说，没跟艾莎说，没跟牧师说（尤其不能跟牧师说）。定榜前夜他照旧通宵，照旧和"夜行玫瑰"争第二。只是偶尔在娱乐室路过 Haide 的时候，会不由自主地看一眼屏幕左下角，然后立刻移开视线。
- **Haide 知不知道他看到了？** 不知道。Haide 从来没提过，眼神也没变过。但有一次，点儿路过娱乐室，Haide 头也不回地说了一句："别看了，学不会的。"点儿走得很快。

## 道具的意义

**游戏手柄**不是玩具，是他的思考工具。**耳机**是他和世界之间的一扇门，他自己决定开还是关。**眼镜**是他看清世界的方式，摘下来的时候表示他不想看清了。
