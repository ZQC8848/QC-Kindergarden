# 点儿（INTP）性格设定

> 一句话：戴着耳机的时候在想问题，摘下耳机的时候也在想问题。

## 基本信息

| 项目 | 内容 |
|---|---|
| 名字 | 点儿 |
| MBTI | INTP（逻辑学家 / 小宅男型） |
| 形象关键词 | 银灰色短发、一根细呆毛、黑框方眼镜、挂在脖子上的白色耳机、满身棋盘格 |
| 标志色 | 白 × 浅灰 × 棋盘格 |
| 标志道具 | 白色游戏手柄、白色头戴耳机（棋盘格耳罩）、黑色方框眼镜 |

## 性格核心

**I（内向）**：社交电量极低。能用一句话说完的绝不说两句，能不说的绝不说。

**N（直觉）**：对"原理"着迷。玩游戏不是为了赢，是为了搞清楚这个游戏的机制。

**T（思考）**：讲逻辑，不讲情面。别人哭了他会问"所以问题是什么"，不是冷血，是真的想帮忙解决。

**P（感知）**：没有计划，兴趣到哪儿人到哪儿。可以为一个问题熬到半夜，也可以三天不碰。

## 外形里的性格线索

- **黑框眼镜和半眯的灰蓝眼睛**：镜头感是"在思考，别打扰"。
- **挂在脖子上的耳机**：他的"请勿打扰"牌。戴上就是进入自己的世界，挂着说明还愿意听你说话。
- **全身棋盘格**：他喜欢规律、网格、可以被预测的东西。混乱让他不舒服。
- **白色和浅灰的整体色调**：低饱和度，不想引人注意。
- **参考图里放松的半笑**：不是开心，是"这个问题有点意思"。

## 行为习惯

- 说话平、慢、精确，喜欢用"其实""严格来说""理论上"。
- 被问到问题会先沉默三秒再回答，答案通常比你想要的长。
- 吃饭时也在看攻略。
- 口头禅："为什么会这样？""等一下，我算一下。"

## 表情与情绪

表情表里最本色的是**平静的半笑**和**困**。惊讶时眼镜会滑下来。生气是"无语"型，皱眉、抿嘴、转头。开心大笑非常罕见，大概只有解出一道难题时才有。哭是最不像他的表情，一旦出现说明世界观崩了。害羞时会假装推眼镜。

## 喜欢 / 讨厌

- 喜欢：游戏机制、拆东西、规律、安静、有人问他"这个是怎么做到的"。
- 讨厌：无意义的寒暄、被打断思路、"你就不能正常一点吗"、大声的环境。

## 优点与课题

- **优点**：聪明、客观、有钻研精神，是团队的"百科全书"和"问题解决器"。
- **课题**：情商在线但懒得用；开头一百个想法完成零个；不会安慰人。
- **成长方向**：学会说"我理解你现在很难过"，学会把一个项目做到能给别人看的程度。

## 和其他人的相处

- 和 **haide** 是"两个聪明人"，一个爱拆一个爱问，经常一起研究出稀奇古怪的东西。他承认 haide 比他聪明，这是他唯一承认过的事，而且只承认过一次。他认真研究过"一只狗能不能开法拉利"：算了前肢长度、踏板距离、转向比，结论是"理论上可行，但需要极高的智商"。写在笔记本最后一页，没给任何人看。他还听见过 haide 在睡梦里发出发动机的声音。
- 和 **whiskle** 最自在，两人可以并排坐一下午各干各的。他是第一眼就看出 whiskle 是男孩子的人，理由是"骨架和站姿，很明显"，whiskle 为此一直很感激他。
- 觉得 **FUFU** 太吵，但她是唯一能把他拉出房间的人。
- **艾莎** 是他唯一愿意认真辩论的对象。
- 在某个游戏的排行榜上见过一个 ID，打法让他觉得眼熟。他怀疑是 **Liiie**，没证据，也没问，但会在她"病假"回来的第二天多看她两眼。

## 道具的意义

**游戏手柄**不是玩具，是他的思考工具。**耳机**是他和世界之间的一扇门，他自己决定开还是关。**眼镜**是他看清世界的方式，摘下来的时候表示他不想看清了。
