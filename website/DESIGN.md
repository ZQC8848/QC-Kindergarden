# QC Kindergarden 项目网站设计案

日期：2026-09-08　状态：已定案，未开工

## 定案

| 项 | 决定 | 被否决的方案与原因 |
|---|---|---|
| 观众 | 群友与一般观众为主；教授通过英文链接进入 | 不做单独的"研究"层。论文入口只放页脚 |
| 语言 | 中英双语，可切换。`/zh/…` 默认给群友，`/en/…` 给教授，根路径跳 `/zh` | 双域名：切换语言要跨站跳转，页面状态不保留；要维护两个部署。域名本身的钱和配置都很便宜，不是理由 |
| 合照 | 用户后续提供合成图，每个角色一个图层 | 模型一次生成 12 人：身份一致性保不住 |
| 3D | Tripo AI 从三视图生成，glb 压到 2 MB 内 | 无 |
| 部署 | Vercel，仓库根目录 `website/` | GitHub Pages：图片优化与重定向不如 Vercel 顺手 |
| 技术栈 | Astro 静态站，构建时把 markdown 解析成 JSON | 纯 Vite 手写路由：i18n 与图片优化都要自己搭 |
| 主题色 | 页面底 `#FAF4EF`，区块与托板 `#F6EAE2`，文字暖棕 `#3D2E2A`，每角色一个强调色取自其立绘场景 | 底色偏粉：12 个强调色压不住。奶白托板：奶色衣物在上面消失 |
| 滚动 | 自由滚动 + 固定章节导航 | scroll-snap：角色卡在手机上超过一屏会卡 |

反转触发：3D 模型平均超过 2 MB 或 Tripo 成品与毛毡风格差距过大，改为三视图伪 3D 作为正式方案而非退路。

## 首页四层

1. **合照** 图层化，滚动视差；每个角色是热区，点击跳到角色页。
2. **角色卡** 桌面 4×3，手机 2 列。立绘 + 名字 + MBTI + 口头禅。悬停时用 CSS 从表情表 3×3 网格里裁一格替换立绘，不需要新素材。
3. **故事集** 按"剧集"列出，每条带出场角色头像，可按角色筛选。第一版无配图，用出场角色立绘拼小分镜。
4. **环境浏览** 一张横向全景长图，横向滚动，热区标注地点并关联故事。素材待生成。

## 角色页

顺序：海报 → 3D 槽位 → 描述 → 故事 → 关系图。

- **海报** 直接用立绘。12 张立绘各自带完整场景与主色（FUFU 橘、Mimi 紫、点儿 藏青…），不是白底图，不需要再铺色。名字 + MBTI + 口头禅叠在场景上或放在其下。
- **3D 槽位** `<model-viewer>`。默认折叠；进入视口且非省流量时才请求 glb；`load` 事件后展开，失败保持折叠并显示三视图旋转条（四视角拖动）。
- **描述** 由性格设定 markdown 的章节直接映射：基本信息、性格核心、外形里的性格线索、行为习惯、喜欢 / 讨厌、优点与课题、道具的意义。
- **故事** 本角色的"额外设定"章节 + 出场的跨角色故事。
- **关系图** 以本角色为中心的放射状布局，边有方向、两端各一句话。点击邻居原地重新居中并切换下方文字；每个节点带"去他的页面"按钮。12 节点不用力导向。

## 颜色规则

验证日期 2026-09-08，见 `scratchpad/bg-compare.png` 的对比（未入库）。

- **角色肤色约 `#EEB9A0`，与桃色页面同一色相，对比度仅 1.5**。奶色衣物（软软、牧师、FUFU、lukos）与页面同明度。因此**抠图角色从不直接放在页面上**：合照图层、三视图旋转条、3D 退路都要垫一块托板加柔和投影。
- 托板用**该角色的强调色**以约 15% 叠在 `#F6EAE2` 上，不用奶白（奶白会吃掉奶色衣物）。
- 强调色只用于托板、标签、装饰。**用作文字时必须加深到对比度 4.5 以上**，橘、浅粉在桃色上只有 3 左右，直接当正文色会不达标。
- 自带场景的立绘作为卡片放在桃色页面上没有问题，深色场景（点儿、陆姚、艾莎、QC）反而给网格加了节奏，不要为它们单独处理。
- 只做浅色，不做深色模式。
- 英文里称 peach / cream，不用 flesh / nude。

## 内容与数据

单一数据源是 `character reference/`，网站不手抄。

```
character reference/<slug>/
  性格设定.md          中文（现有）
  性格设定.en.md       英文，同样的标题结构（待翻译）
  <slug>.png           立绘
  turnaround/ expressions/
website/
  src/content/stories/<slug>.zh.md  frontmatter: cast, location, date
  src/content/stories/<slug>.en.md
  src/data/relationships.json       { from, to, zh, en, kind }
  src/data/locations.json           全景热区
  public/models/<slug>.glb          Tripo 产物，gltf-transform 压缩
```

构建时脚本读取两种语言的性格设定，按 `## ` 标题切块生成 JSON。英文文件缺失时该角色英文页显示中文并标注"未翻译"，不阻塞构建。

图片：源 PNG 4–6 MB，构建时经 Astro `<Image>` 输出 webp，最大边 1600。
